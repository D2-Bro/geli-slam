새 비접촉 속도 계산
기준 시각 t_a는 마지막 접촉 수락 시각이다. 목표 시각 t는 그 이후의 비접촉 이미지 시각이다.
t_a까지 수락한 접촉 위치와 IMU 측정만 사용하여 진입 속도를 구한다.
inertial_quadratic은 접촉 위치 이력에서 측정 IMU 운동을 먼저 제거한다.
그 잔차에 2차 곡선을 맞춘다. 마지막 접촉 시각의 속도만 보정에 사용한다.
이력 시작 시각을 t_0, 마지막 접촉 시각을 t_a라고 한다. 모든 위치와 속도는 고정 trial 축의 IMU 원점 값이다.
원시 IMU를 t_0부터 각 접촉 시각 t_j까지 사전 적분한다. 바이어스는 t_a의 수락 값을 사용한다.
R_0 = R_a * DeltaR_0a^T; tau_j = t_j - t_0.
D_j = 0.5 * g * tau_j^2 + R_0 * DeltaP_0j.
q_j = (p_j - p_a) - (D_j - D_a).
q_j = u * (t_j - t_a) + 0.5 * c * (t_j - t_a)^2로 맞춘다.
v_seed = u + g * (t_a - t_0) + R_0 * DeltaV_0a; delta_v = v_seed - v_a.
곡선의 가속도 계수는 비접촉 구간에 외삽하지 않는다.
기본 조건은 최근 0.4초, 접촉 표본 5개 이상, 시간 폭 0.3초 이상이다.
접촉 표본 간격은 0.15초 이하여야 한다. 곡선 오차는 0.05 mm 이하여야 한다.
속도 변화는 20 mm/s 이하여야 한다. 조건을 만족하지 않으면 기존 VI 속도를 유지한다.
접촉 중단, IMU 복구, trial 변경, 백엔드 좌표 보정 시에는 이력을 끊는다.
접촉 없는 구간에서 얻은 IMU 예측을 촉각 측정으로 다시 사용하지 않는다.
보정은 별도 비접촉 예측에만 적용한다. 접촉 수락 상태와 marginal prior를 변경하지 않는다.
2026-10-22 수정: 위 분리는 비접촉 전파 중에만 유지한다. IMU recovery 수락 시에는
target 위치에 delta_v * (t_target - t_anchor), 속도에 delta_v를 더한다.
원래 IMU 전파 prior의 target 위치·속도 분포도 동일하게 이동한다. 전체 A/rhs와
기준 pose 사이의 상관정보를 유지하고, 다른 시각의 pose와 첫 고정 pose는 이동하지 않는다.
피팅 보정값은 확정값으로 취급한다. 피팅 불확실성을 새로 추정하거나 독립 속도 관측을
추가하지 않는다. 수락 후에는 보정된 recovery state를 다음 기준으로 사용하고 이전
보정값을 지워 중복 적용을 막는다. 비접촉과 recovery가 서로 다른 속도로 발행되던
위치 불연속을 제거하기 위한 변경이다.
상관된 과거 접촉 위치를 독립된 새 최적화 측정으로 다시 넣지 않는다. 곡선 오차를 상태 공분산으로 쓰지도 않는다.
p_new(t) = p_native(t) + delta_v * (t - t_a)
v_new(t) = v_native(t) + delta_v
자세와 바이어스는 이 보정으로 변경하지 않는다.
이 보정만 적용하면 figure8 추가 변위 RMSE는 1.621 -> 0.514 mm다.
41개 비교에서 비접촉 이외의 상태 33,863개가 기준과 같았다.
이 결과는 접촉 상태의 정확도 개선을 뜻하지 않는다. IMU 복구가 발생하면 기존 VI 예측으로 돌아갈 수 있다.

정지 IMU 초기 공분산 계산
정지 측정 구간은 1.0 -> 2.9 s다. 표본은 381개다. 첫 접촉 수락 시각은 4.35 s다.
자이로 바이어스 평균과 그 불확실성은 정지 구간의 마지막 시각 2.9 s에 속한다.
그 후 2.9 -> 4.35 s의 IMU 초기화 전파가 첫 접촉 상태와 상관 공분산을 만든다.
gyro_bias_uncertainty_from_samples는 정지 평균값을 바꾸지 않는다. 그 평균의 초기 불확실성만 계산한다.
N개 표본의 시각 차이를 dt_i라고 한다. 첫 표본의 잡음 주기에는 첫 관측 주기를 사용한다.
백색잡음 분산: sigma_w^2 * sum(1 / dt_i) / N^2.
구간 끝 바이어스와 표본 평균의 random walk 분산: sigma_wb^2 * sum(dt_i * (i/N)^2), i=1..N-1.
이 식은 독립 백색잡음과 바이어스 random walk 모형에 대한 식이다. 표본의 실제 잡음 분산을 새로 보정한 식은 아니다.
현재 설정에서는 정지 기준 시각의 자이로 바이어스 표준편차가 0.01 -> 0.000117237 rad/s가 된다.
비균일 표본의 전체 Brownian 공분산 계산과 대조했다. 독립 Monte Carlo 12,000회와도 대조했다.
설정으로 고정한 바이어스는 계속 상수로 취급한다. 옵션 기본값은 false다.

IMU 백색잡음·바이어스 random walk 설정값과 midpoint 적분식은 유지했다.
simulation_ideal_imu와 GT 이전 상태 대입은 꺼져 있다. 기존 가속도 바이어스 보정값은 유지했다.
선택한 전용 설정에서 GT는 평가에 사용한다. 자세·속도 초기화와 속도 보정에는 GT를 넣지 않는다.
가중치와 초기화도 함께 바꾸었으므로 전체 개선을 속도 보정 하나의 효과로 해석하면 안 된다.
gtsam_integration_sigma_m은 예전 이름이다. 실제 단위는 m/sqrt(s)다. GTSAM은 sigma^2 * dt를 위치 공분산에 더한다.
이 항은 가속도계·자이로 측정 잡음과 별도다. 값만 줄인 실험은 크게 나빠졌다.

입력 잡음을 더한 검증
같은 bag에 추가 Gaussian 잡음을 넣었다. IMU 시각과 촉각 이미지는 유지했다.
추가 density는 sqrt(m^2 - 1) * 기존 설정 density다. m은 1.5와 2.0이다.
원래 bag의 잡음은 남아 있다. 따라서 m을 실제 총 잡음 배수로 해석하면 안 된다.
각 조건은 서로 다른 seed 5개를 사용했다.

채택하지 않은 계산
위치 적분 불확실성만 낮추면 추적 실패와 오차가 늘었다.

곡선 가속도 보정을 비접촉 구간에 계속 적용한 방법은 검증 구간의 개선이 일관되지 않았다.
접촉 이력으로 속도·기울기·바이어스를 함께 다시 맞춘 독립 실험의 최선 RMSE는 약 0.66 mm였다.

현재 bag에서는 orb_slam3 시작 자세 적분이 midpoint보다 나빴다. 적분식은 바꾸지 않았다.
매우 큰 촉각 가중치 1e6에서는 발산했다. 이 설정은 사용하지 않는다.

실행 인자, 설정 복사본, 노드 로그를 각 isolated_ros 폴더에 저장했다.
별도 프로세스의 ROS 파라미터 조회는 환경의 CLI 의존성과 통신 제약으로 완료하지 못했다.
저장 원본 실행은 보존한 baseline_source를 PYTHONPATH 앞에 넣어 사용했다. 실제 import 경로도 확인했다.
두 실행 모두 그림 저장 중 기본 5초 종료 제한에 따른 SIGTERM 로그가 있었다. 저장 완료 후 모든 노드가 종료했다.
